# STUDENT_DOCS

## Вступ

### Актуальність теми
Сайт-візитка залишається актуальним інструментом представлення для компаній будь-якого розміру — від малих архітектурних бюро до середніх і навіть великих фірм. Сайт-візитка має важливу перевагу — він дозволяє швидко, лаконічно та зрозуміло донести ключову інформацію про компанію, її цінності, послуги та контактні дані.

### Мета роботи
Метою цієї курсової роботи є розробка зручного та функціонального сайту-візитки для архітектурного бюро, що забезпечує презентацію послуг, портфоліо, публічної інформації та зручні канали зворотного зв’язку.

### Завдання роботи
- провести аналіз аналогів і вимог до сайту-візитки;
- спроєктувати структуру бази даних та моделі даних;
- реалізувати публічну частину сайту (Головна, Про нас, Проєкти, Публічна інформація, Контакти);
- реалізувати реєстрацію та авторизацію користувачів;
- розробити адміністративну панель для CRUD-операцій;
- провести тестування функціоналу та усунення помилок.

### Об’єкт дослідження
Вебсайт-візитка як інформаційна система для архітектурного бюро.

### Предмет дослідження
Процес проєктування та реалізації вебзастосунку на базі MVC (моделі, контролери, представлення, база даних).

### Практичне значення
Розроблений продукт може бути використаний як готовий сайт-візитка для реального архітектурного бюро або як навчальний приклад застосування PHP, Yii2 та MySQL у веброзробці.

---

## Умовні позначення

- **MVC** — Model-View-Controller (архітектурний шаблон проєктування)
- **CRUD** — Create, Read, Update, Delete (операції з даними)
- **PHP** — серверна мова програмування
- **Yii2** — PHP-фреймворк з підтримкою MVC
- **MySQL** — реляційна система управління базами даних
- **phpMyAdmin** — вебінтерфейс для керування MySQL
- **Laragon** — локальне середовище розробки
- **VS Code** — середовище розробки

---

## 1. Опис технологічного стеку

Для реалізації проєкту було обрано сучасний стек вебтехнологій, який забезпечує стабільність, масштабованість та швидкість розробки.

### 1.1 Серверна частина
Основною мовою програмування є **PHP**. Вона використовується для обробки HTTP-запитів, взаємодії з базою даних та формування динамічного контенту.

### 1.2 Фреймворк
Для побудови архітектури застосунку використано **Yii2**, який реалізує шаблон MVC та містить вбудовані механізми авторизації, валідації та роботи з моделями.

### 1.3 База даних
Як система управління базами даних використовується **MySQL**, яка забезпечує збереження даних про користувачів, проєкти, послуги та інші сутності.

#### Структура основних таблиць:
- **user** — користувачі системи
- **project** — портфоліо проєктів
- **service** — послуги бюро
- **about_us** — інформація про компанію
- **public_info** — публічні матеріали
- **comment** — відгуки користувачів

### 1.4 Інструменти адміністрування
Для роботи з базою даних використовується **phpMyAdmin**, який дозволяє створювати таблиці та виконувати SQL-запити.

### 1.5 Локальне середовище
Для розробки використовується **Laragon**, що містить вебсервер, PHP та MySQL для локального тестування.

### 1.6 Середовище розробки
Розробка здійснюється у **Visual Studio Code**, який забезпечує зручну роботу з кодом та Git.

### 1.7 Клієнтська частина
Інтерфейс реалізовано за допомогою **HTML5**, **CSS3** та JavaScript.

### 1.8 Архітектура
Застосунок побудовано за принципом **MVC**:
- Model — робота з базою даних;
- View — інтерфейс користувача;
- Controller — бізнес-логіка та обробка запитів.

### 1.9 Безпека
Передбачено:
- хешування паролів;
- перевірку ролей користувачів;
- валідацію та фільтрацію даних;
- обмеження доступу до адміністративної частини.

## Висновки

У результаті роботи було розроблено функціональний сайт-візитку для архітектурного бюро, який реалізує основні вимоги: презентацію послуг, портфоліо, публічну інформацію, контактні дані, систему авторизації та адміністративну панель.

Застосування Yii2 та архітектури MVC дозволило структурувати код і спростити підтримку системи.

Проведене тестування підтвердило коректну роботу основних модулів: навігації, форм авторизації, CRUD-операцій та взаємодії з базою даних.

Проєкт має практичну цінність як готове рішення для малого бізнесу та як навчальна база для подальшого розвитку.

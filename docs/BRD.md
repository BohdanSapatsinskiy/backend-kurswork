# Business Requirements Document (BRD)

## 1. Introduction

Метою проєкту є розробка сайту-візитки для архітектурного бюро, який забезпечує представлення інформації про компанію, її послуги та реалізовані проєкти. Сайт має слугувати основним джерелом інформації для потенційних клієнтів та партнерів.

## 2. Business Goals

* Забезпечити онлайн-присутність архітектурного бюро
* Представити портфоліо виконаних проєктів
* Надати клієнтам доступ до актуальної інформації про послуги
* Забезпечити можливість зворотного зв’язку
* Надати адміністраторам можливість оновлення контенту без зміни коду

## 3. Target Audience

* Потенційні клієнти архітектурного бюро
* Партнери та інвестори
* Адміністратори сайту (персонал компанії)

## 4. User Roles

### Guest (незареєстрований користувач)

* Перегляд сторінок сайту
* Ознайомлення з інформацією про компанію, послуги та проєкти

### User (зареєстрований користувач)

* Усі можливості Guest
* Можливість залишати відгуки
* Відправка звернень через форму зворотного зв’язку
  (дані надсилаються на електронну пошту власника сайту для уточнення або замовлення послуг)

### Admin (адміністратор)

* Повний доступ до керування контентом
* Додавання та редагування постів/проєктів
* Керування документами у розділі «Публічна інформація»
* Блокування та видалення користувачів
* Модерація відгуків

## 5. Functional Requirements

Система повинна забезпечувати:

* Відображення інформації про послуги
* Відображення інформації про компанію
* Перегляд галереї проєктів
* Додавання нових проєктів (адміністратором)
* Перегляд та додавання відгуків
* Доступ до публічних документів
* Відображення контактної інформації
* Реєстрацію та авторизацію користувачів
* Адміністративну панель для керування контентом

## 6. Non-functional Requirements

* Зручний інтерфейс користувача
* Швидке завантаження сторінок
* Безпечне зберігання даних користувачів
* Масштабованість системи
* Кросбраузерна сумісність

## 7. Constraints

* Використання PHP та фреймворку Yii2
* Обмежений час розробки (в рамках курсового проєкту)
* Використання MySQL як системи керування базою даних

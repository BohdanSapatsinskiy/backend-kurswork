# System Specification Document (SSD)

## 1. System Overview

Система являє собою вебзастосунок у вигляді сайту-візитки для архітектурного бюро. Вона дозволяє користувачам переглядати інформацію про компанію, її послуги та реалізовані проєкти, а також взаємодіяти з контентом через відгуки та форму зворотного зв’язку.

## 2. Architecture

Система побудована на основі архітектурного шаблону MVC (Model–View–Controller), який забезпечує розділення логіки застосунку на три основні компоненти:

* **Model** — відповідає за роботу з даними та базою даних
* **View** — відповідає за відображення інтерфейсу користувача
* **Controller** — обробляє HTTP-запити та керує взаємодією між Model і View

Такий підхід дозволяє підвищити підтримуваність, масштабованість і повторне використання коду.

## 3. Technologies

У проєкті використано такі технології:

* Backend: PHP (фреймворк Yii2)
* Frontend: HTML, CSS, JavaScript
* Database: MySQL
* Development environment: Visual Studio Code
* Database management: phpMyAdmin

## 4. System Components

Система складається з наступних компонентів:

* **Клієнтська частина** — веббраузер користувача
* **Серверна частина** — PHP-застосунок
* **База даних** — MySQL

Взаємодія між компонентами відбувається через HTTP-запити.

## 5. System Modules and Components

У системі реалізовано розподіл логіки відповідно до архітектури MVC (Model–View–Controller).

### 5.1 Models

Моделі відповідають за роботу з даними, взаємодію з базою даних та бізнес-логіку.

* **AboutUs.php** — робота з інформацією про компанію
* **Comment.php** — обробка та збереження відгуків
* **ContactForm.php** — обробка форми зворотного зв’язку
* **LoginForm.php** — авторизація користувачів
* **Project.php** — керування проєктами
* **PublicInfo.php** — робота з публічними документами
* **RegisterForm.php** — реєстрація користувачів
* **Service.php** — робота з послугами
* **User.php** — модель користувача та ролей

### 5.2 Controllers

Контролери відповідають за обробку запитів:

* **SiteController.php**
  Обробляє запити публічної частини сайту:

  * головна сторінка
  * «Про нас»
  * контакти
  * перегляд послуг і проєктів

* **UserController.php**
  Реалізує:

  * реєстрацію
  * авторизацію
  * управління сесією

* **AdminController.php**
  Забезпечує:

  * створення, редагування та видалення записів
  * керування контентом (проєкти, послуги, документи)
  * модерацію коментарів
  * управління користувачами

### 5.3 Interaction Between Components

1. Користувач надсилає HTTP-запит через браузер
2. Контролер приймає запит
3. Контролер викликає відповідну модель
4. Модель взаємодіє з базою даних
5. Результат передається у View
6. View відображає дані користувачу

## 6. Database Design

Система використовує реляційну базу даних MySQL з такими основними таблицями:

* **service** (title, about, img)
* **about_us** (title, description, content)
* **project** (title, description, date, image)
* **public_info** (title, file_path, created_at)
* **comment** (user_id, text, rating, created_at, status)
* **user** (name, email, password, created_at, is_admin)

## 7. API Design

Система використовує PHP-ендпоінти для обробки запитів користувача.
Вони виконують роль API та забезпечують взаємодію між клієнтською частиною і сервером.

Основні типи операцій:

* авторизація користувачів
* отримання даних з бази
* додавання та редагування контенту
* обробка форм (відгуки, контактні запити)

Детальний опис наведено у файлі **API.md**.

## 8. Security

У системі реалізовані наступні механізми безпеки:

* Шифрування паролів користувачів
* Перевірка прав доступу (роль admin)
* Валідація вхідних даних
* Захист від несанкціонованого доступу до адміністративної частини

## 9. User Management

Система підтримує:

* Реєстрацію нових користувачів
* Авторизацію (вхід у систему)
* Розмежування прав доступу (користувач / адміністратор)

## 10. Admin Panel

Адміністративна панель дозволяє:

* Додавати, редагувати та видаляти записи
* Керувати всіма таблицями бази даних
* Модерувати коментарі
* Керувати користувачами

## 11. Deployment

Система може бути розгорнута на будь-якому вебсервері з підтримкою PHP та MySQL.

Для запуску необхідно:

* встановити вебсервер
* налаштувати базу даних
* розгорнути файли проєкту
